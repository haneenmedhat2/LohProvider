# Merchant fonts

`Cairo-ExtraBold.ttf` supplies the 800 weight used by the Arabic offers design. It is version 3.130, downloaded from the [Expo Google Fonts Cairo package](https://github.com/expo/google-fonts/tree/main/font-packages/cairo/800ExtraBold). Its PostScript name is `Cairo-ExtraBold`.

The [upstream Cairo license](https://github.com/google/fonts/blob/main/ofl/cairo/OFL.txt) is included in `Cairo-OFL.txt`. Existing Cairo weights are retained. The new weight is used only by the requested Arabic offers headings; other screens retain their existing typography.
